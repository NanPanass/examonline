# ExamFlow — ระบบสอบออนไลน์ (รวม Stitch + ExamHub)

**ระบบหลัก = Stitch (ExamFlow)** เก็บไว้ครบทุกอย่าง: ดีไซน์ โทเค็นสี/ฟอนต์/spacing, header + เมนู 4 หน้า, footer
และหน้า "ผลสอบ & สถิติ" ต้นฉบับ (เก็บไว้เต็มใน `public/index.html` เป็น `<template id="stitch-original">` กดดูได้ที่หน้าผลสอบ)
ไฟล์ต้นฉบับอยู่ที่ `design/` ไม่ถูกแก้ไข

ส่วนที่เสริมจาก **examonline (ExamHub)** เข้ามาในเปลือกของ Stitch:

| เมนูใน Stitch | สิ่งที่เพิ่มเข้าไป (มาจาก examonline) |
|---|---|
| Portal ข้อสอบ | รายการชุดข้อสอบสาธารณะ ค้นหา/กรองหมวด ทำข้อสอบได้โดยไม่ต้องสมัคร โหมดฝึกฝน/สอบจริง สลับข้อ ปักธงทบทวน; หน้าห้องสอบตาม layout ของ DESIGN.md (canvas ซ้าย + palette/timer ขวา) |
| ห้องสอบ Live Exam | ห้องสอบสดแบบ Kahoot (PIN 6 หลัก, Socket.IO, คะแนนโบนัสตามความเร็ว, กระดานผู้นำ) |
| จัดการข้อสอบ | สร้าง/แก้ชุดข้อสอบและข้อสอบ, รูปในโจทย์/ตัวเลือก, จัดการผู้ใช้/สิทธิ์แอดมิน, **นำเข้าข้อสอบจากไฟล์** (.docx .xlsx .xls .csv .pdf รูปภาพ .md .txt) พร้อม**จับเฉลยจากไฟล์** (เฉลยติดโจทย์ / หน้าเฉลยท้ายเล่ม / คอลัมน์ Excel) แล้วให้ตรวจทานก่อนบันทึก |
| ผลสอบ & สถิติ | ประวัติผลสอบจริง + หน้ารายละเอียดแบบ Itemized Solution Key (คะแนน, อันดับ, เวลา, ความแม่นยำ, เฉลยรายข้อ) |

ระบบหลังบ้านทั้งหมด: Express + Turso(libSQL) + JWT + ตรวจคำตอบที่เซิร์ฟเวอร์ (เฉลยไม่ถูกส่งไปเบราว์เซอร์ระหว่างสอบ)

## สิ่งที่เพิ่ม/แก้ระหว่างรวมระบบ
- ตัวอ่านตาราง Excel/CSV แบบรู้จักคอลัมน์ `[โจทย์|เฉลย]` และ `[โจทย์|ตัวเลือก…|เฉลย]` (ของเดิมอ่านแบบคอลัมน์ไม่ได้ และได้เฉลยผิดเมื่อไม่มี AI key)
- ข้อที่ไม่เจอเฉลยในไฟล์ถูกติดธง `keyMissing` และไฮไลต์เหลืองในหน้าตรวจทาน (ของเดิมตั้งเป็นตัวเลือกแรกเงียบๆ)
- `/api/exam/:sid/check` ใช้ได้เฉพาะโหมดฝึกฝน (ของเดิมโหมดสอบจริงก็เรียกขอเฉลยทีละข้อได้)
- `GET /api/results/:id` เพิ่ม rank / จำนวนผู้สอบ / ค่าเฉลี่ย
- `NODE_ENV=production` ต้องตั้ง `JWT_SECRET` ไม่งั้นเซิร์ฟเวอร์ไม่ยอมรัน
- โมเดล AI เริ่มต้นเปลี่ยนเป็น `claude-sonnet-5-5`

## รัน
```bash
npm install
cp .env.example .env      # ทดสอบเร็ว: TURSO_DATABASE_URL=file:./local.db  (ไม่ต้องมี token)
npm start                 # http://localhost:3000  — ผู้สมัครคนแรกเป็นแอดมินอัตโนมัติ
```
Deploy Vercel/Turso เหมือน examonline เดิม (`api/index.js`, `vercel.json` คงไว้)

## ข้อจำกัด
- ห้องสอบสดเก็บสถานะใน memory ของ process เดียว → ควรรันบนโฮสต์ที่มี process ต่อเนื่อง (เช่น Render) ไม่ใช่ serverless หลาย instance
- รูปที่อัปโหลดเก็บเป็น base64 ในฐานข้อมูล (จำกัด 1.5MB/รูป)
- หน้า "รายงานต้นแบบ" ของ Stitch เป็นข้อมูลตัวอย่างคงที่ ไม่ได้ผูกกับฐานข้อมูล (รายงานจริงคือหน้ารายละเอียดผลสอบ)
- ยังไม่มี Google Sign-in (มีแค่อีเมล+รหัสผ่าน) และไม่มี rate limiting
