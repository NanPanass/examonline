# ExamOnline — ระบบสอบออนไลน์

โปรเจกต์ **examonline** ที่ควบรวมแล้ว: ใช้ **Stitch เป็นระบบหลัก** (โครงหน้า ดีไซน์ โทเค็นสี คอมโพเนนต์)
และนำ **หลักการทำงานของ examonline เดิม** (backend, auth, ตรวจข้อสอบฝั่งเซิร์ฟเวอร์, รูปภาพ, นำเข้าไฟล์ด้วย AI,
ห้องสอบสดแบบ Kahoot) มาใช้ภายใต้ดีไซน์นั้น ชื่อโปรเจกต์ยังเป็น `examonline` เช่นเดิม

ไฟล์ต้นฉบับของ Stitch เก็บไว้อ้างอิงที่ `design/stitch/` (DESIGN.md, code.html, screen.png)

## ควบรวมอะไรเข้ากับอะไร

| เมนูใน Stitch | หน้าที่ทำงานจริง (จาก examonline) |
|---|---|
| Portal ข้อสอบ | แคตตาล็อกชุดข้อสอบสาธารณะ เลือกโหมด/รูปแบบ แล้วเริ่มสอบได้เลยโดยไม่ต้องสมัครสมาชิก |
| ห้องสอบ Live Exam | ห้องสอบสดแบบ Kahoot (PIN 6 หลัก, Socket.IO, คะแนนโบนัสตามความเร็ว, กระดานผู้นำ) |
| จัดการข้อสอบ (เฉพาะแอดมิน) | จัดการชุดข้อสอบ/ข้อสอบ/ผู้ใช้, รูปในโจทย์และตัวเลือก, นำเข้าจากไฟล์ด้วย AI (Dropzone ตาม DESIGN.md) |
| ผลสอบ & สถิติ | ประวัติผลสอบ + หน้าผลสอบแบบ Stitch (การ์ดคะแนน, อันดับ, เวลา, ความถูกต้อง, วิเคราะห์รายตอน, เรดาร์, เฉลยรายข้อ) |

ห้องสอบ (หน้าทำข้อสอบ) ใช้เลย์เอาต์ตาม DESIGN.md: พื้นที่โจทย์ ≤ 780px + แถบแผนผังข้อสอบด้านขวา
(จอเล็กเปลี่ยนเป็นแถบเลื่อนแนวนอน), ตัวจับเวลาเตือนสีแดงเมื่อเหลือ < 5 นาที, สีแผนผัง ตอบแล้ว/ปักธง/ข้อปัจจุบัน

### ข้อมูลที่หน้าผลสอบของ Stitch ต้องการ → ที่มาจริงในระบบ

- **อันดับ / ค่าเฉลี่ย / สูงสุด**: คำนวณจากผลสอบ "โหมดสอบจริง" ของชุดเดียวกัน (ไม่นับผลห้องสอบสดและโหมดฝึกฝน)
- **เวลาที่ใช้รายข้อ**: หน้าเว็บจับเวลาต่อข้อแล้วส่งไปกับการส่งข้อสอบ
- **วิเคราะห์รายตอน + เรดาร์**: แบ่งตาม "คำอธิบายช่วงตอน" (`section_note`) ที่ใส่ไว้ในข้อสอบ — ชุดข้อสอบที่ไม่มีช่วงตอนจะไม่แสดงส่วนนี้
  (เรดาร์แสดงเมื่อมี 3–8 ตอน)
- **สูตรคณิตศาสตร์**: พิมพ์แบบ `\( x^2 \)` ในโจทย์/ตัวเลือก/คำอธิบายได้ (แสดงผลด้วย KaTeX)
- **จำนวนครั้งที่ออกจากหน้าจอระหว่างสอบจริง**: นับด้วย `visibilitychange` และแสดงเป็นคำเตือนในหน้าผลสอบ

### ส่วนของ Stitch ที่ไม่ได้ย้ายมา (ไม่มี backend รองรับ)

แชร์ไป Google Classroom, ป้าย Google Workspace, ปุ่ม Google SSO, กระดิ่งแจ้งเตือน, ใบรับรองผลคะแนน PDF,
ยื่นคำร้องขอตรวจซ้ำ/ติดต่ออาจารย์, ค่าเฉลี่ยห้องเรียนรายหมวดในเรดาร์, ธีมมืด (Stitch ไม่ได้กำหนดโทเค็นสีมืดไว้)
— ปุ่ม "พิมพ์ / บันทึกเป็น PDF" ในหน้าผลสอบใช้ฟังก์ชันพิมพ์ของเบราว์เซอร์แทนใบรับรอง

## การเปลี่ยนแปลงฝั่งเซิร์ฟเวอร์ (`server/server.js`)

- `POST /api/exam/start` ติดป้าย "ตอน/หมวด" ให้แต่ละข้อจาก `section_note`
- `POST /api/exam/:sid/submit` รับ `qtimes` (วินาทีต่อข้อ) และบันทึก `section`, `q_image`, `sec`, `rightIndex` ลงรายละเอียดผลสอบ
- `GET /api/results/:id` ส่ง `set_id`, `examinee` และ `stats` (อันดับ/จำนวนผู้สอบ/ค่าเฉลี่ย/สูงสุด/เวลาเฉลี่ย/เวลาที่กำหนด) เพิ่ม
- ผลสอบเก่าที่บันทึกไว้ก่อนหน้านี้ยังเปิดดูได้ แต่จะไม่มีเวลารายข้อ รูปโจทย์ และการแบ่งตอน
- นอกนั้น (auth, ตาราง, ห้องสอบสด, นำเข้าไฟล์) ไม่เปลี่ยน

## รันในเครื่อง

```bash
npm install
cp .env.example .env   # แล้วใส่ค่าจริงในไฟล์ .env
npm start
```

เปิด `http://localhost:3000` — ผู้ใช้ที่สมัครคนแรกจะเป็นแอดมินอัตโนมัติ ตารางและชุดข้อสอบตัวอย่าง 2 ชุดถูกสร้างให้ตอนรันครั้งแรก

ตัวแปรสภาพแวดล้อม: `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `JWT_SECRET` (จำเป็น) และ `ANTHROPIC_API_KEY` (ไม่บังคับ — ใช้กับปุ่มนำเข้าไฟล์ด้วย AI)
ทดสอบแบบไม่ต้องมี Turso ได้โดยตั้ง `TURSO_DATABASE_URL=file:local.db`

### ตั้งค่า Turso

```bash
curl -sSfL https://get.tur.so/install.sh | bash
turso auth login
turso db create examonline
turso db show examonline --url
turso db tokens create examonline
```

## Deploy บน Vercel

1. Push โค้ดขึ้น GitHub แล้ว New Project บน https://vercel.com
2. ตั้ง Environment Variables: `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `JWT_SECRET`
3. Deploy — `api/index.js` เป็น Function หลักตาม `vercel.json` (รองรับ WebSocket/Socket.IO ที่ export เป็น http.Server)

ข้อจำกัดที่ควรรู้:
- ห้องสอบสดเก็บสถานะห้องไว้ใน memory ของ 1 process — ถ้า Vercel กระจายหลาย instance โฮสต์กับผู้เล่นอาจไปคนละ instance
  ถ้าฟีเจอร์นี้สำคัญ ให้รันบนโฮสต์แบบ process ต่อเนื่อง (เช่น Render)
- รูปที่อัปโหลดถูกฝังเป็น base64 ในฐานข้อมูล (จำกัด 1.5MB/รูป) ไม่ต้องใช้ object storage แต่แถวข้อมูลจะใหญ่ขึ้น
- หน้าเว็บโหลด Tailwind จาก `cdn.tailwindcss.com` ตามโค้ด Stitch ซึ่งเหมาะกับต้นแบบ/ใช้งานขนาดเล็ก
  ถ้าขึ้นใช้งานจริงจังควร build Tailwind เป็นไฟล์ CSS เอง

## โครงสร้างไฟล์

```
examonline/
  api/index.js          จุดเข้า Vercel Functions
  server/
    server.js           REST API + Socket.IO (ห้องสอบสด)
    db.js               Turso (libSQL) schema + seed
    auth.js             bcrypt + JWT + middleware
  public/
    index.html          เปลือกหน้า + โทเค็นสี/คอมโพเนนต์จาก Stitch
    app.js              ทุกหน้าจอ (Portal, ห้องสอบ, ผลสอบ, หลังบ้าน, ห้องสอบสด)
  design/stitch/        ต้นฉบับจาก Stitch (อ้างอิง)
```
